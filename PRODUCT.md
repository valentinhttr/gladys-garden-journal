# Garden Journal

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Gladys users managing plants inside the home and outdoors, including beginners who do not know plant-care cycles.

## Product Purpose

Track plants or batches, their locations and care history; surface checks and weather-related protection needs through Gladys widgets and scenes.

## Stack

User-requested official Gladys external integration JavaScript template and SDK. Gladys owns rendering; no separate frontend or website.

## Capabilities and Constraints

Local persistence, configuration forms, widgets, scene triggers/actions, French/English documentation, SECURITY.md, CHANGELOG.md and AGENTS.md. Public source repository creation is authorized under valentinhttr; image/release publication and store listing are deferred. Weather uses Gladys' provider-neutral API; separate API credentials are currently needed for that route.

## Brand Commitments

User-approved technical name: `gladys-garden-journal`. Display name: Garden Journal. Existing Gladys native components remain the visual authority.

## Product Principles

- A reminder prompts observation; it is not a botanical prescription.
- Missing forecasts remain visibly unknown.
- History records actual care and movement, never inferred actions.
- Keep setup in Gladys and preserve offline inventory functionality.

## Open Decisions

Publication owner: valentinhttr. The actual deployment instance is not provided. Photos, sensors and vacation mode are future possibilities, not implemented capabilities.
